## Features

- Drag with a mouse; a flick coasts and lands on a cover.
- The value changes as each cover passes the center, so a caption keeps up while scrolling.

## Usage

```tsx
import {
  CoverFlow,
  CoverFlowCover,
  CoverFlowItem,
  CoverFlowReflection,
} from "@/components/cover-flow"
```

```tsx
<CoverFlow aria-label="Albums">
  <CoverFlowItem value="album">
    <CoverFlowCover>
      <img src="/album.jpg" alt="Album" />
      <CoverFlowReflection>
        <img src="/album.jpg" alt="" />
      </CoverFlowReflection>
    </CoverFlowCover>
  </CoverFlowItem>
</CoverFlow>
```

`CoverFlowReflection` is optional and needs the same content as the cover.

## Composition

Use the following composition to build a `CoverFlow`

```text
CoverFlow
└── CoverFlowItem
    └── CoverFlowCover
        └── CoverFlowReflection
```

### CSS variables

Set them on `CoverFlow`, for example `className="[--cover-flow-size:--spacing(56)]"`.

| Variable             | Default         | Description                                |
| -------------------- | --------------- | ------------------------------------------ |
| `--cover-flow-size`  | `--spacing(48)` | Width and height of a cover.               |
| `--cover-flow-angle` | `70deg`         | How far the side covers turn.              |
| `--cover-flow-first` | `size * 0.64`   | Gap between the center and the next cover. |
| `--cover-flow-step`  | `size * 0.26`   | Gap between the stacked side covers.       |
| `--cover-flow-depth` | `size * -0.75`  | How far the side covers sit back.          |

### Data attributes

| Attribute       | Element                           | Present when                |
| --------------- | --------------------------------- | --------------------------- |
| `data-selected` | `CoverFlowItem`, `CoverFlowCover` | The cover is at the center. |

## Accessibility

- The row is a listbox and the centered cover its selected option. Name the row with `aria-label` and each cover with its image's `alt`.
- `ArrowLeft` and `ArrowRight` step through the covers, `Home` and `End` jump to the ends.
- With `prefers-reduced-motion`, clicks and keys jump to the cover instead of gliding.
