## Features

Built on top of [ramka](https://ramka.dev), unstyled lightbox primitives for React. ramka handles the behavior, gestures, and accessibility. This component adds the styles.

- Morphs from the thumbnail on open and back on close.
- Swipe between images, pull down to close.
- Pinch or double-tap to zoom, then drag to pan.

## Use cases

- Photo galleries on a portfolio or travel page.
- Product images on a store page.
- Screenshots in a blog post or changelog.

## Usage

```tsx
import {
  Lightbox,
  LightboxCaption,
  LightboxClose,
  LightboxContent,
  LightboxCounter,
  LightboxFooter,
  LightboxHeader,
  LightboxItem,
  LightboxMedia,
  LightboxNext,
  LightboxPrevious,
  LightboxSlide,
  LightboxSlides,
  LightboxTrigger,
  LightboxZoom,
  LightboxZoomIn,
  LightboxZoomOut,
} from "@/components/lightbox"
```

```tsx
<Lightbox>
  {photos.map((photo, index) => (
    <LightboxTrigger key={photo.src} index={index}>
      {({ imageRef }) => <img ref={imageRef} src={photo.src} alt={photo.alt} />}
    </LightboxTrigger>
  ))}

  <LightboxContent aria-label="Photos">
    <LightboxSlides aria-label="Photos" aria-roledescription="carousel">
      {photos.map((photo, index) => (
        <LightboxSlide key={photo.src}>
          <LightboxItem index={index} caption={photo.caption}>
            <LightboxZoom>
              <LightboxMedia width={photo.width} height={photo.height}>
                <img src={photo.src} alt={photo.alt} />
              </LightboxMedia>
            </LightboxZoom>
          </LightboxItem>
        </LightboxSlide>
      ))}
    </LightboxSlides>

    <LightboxHeader>
      <LightboxZoomOut />
      <LightboxZoomIn />
      <LightboxClose />
    </LightboxHeader>

    <LightboxPrevious />
    <LightboxNext />

    <LightboxFooter>
      <LightboxCaption />
      <LightboxCounter />
    </LightboxFooter>
  </LightboxContent>
</Lightbox>
```

<Callout>
  The thumbnail and the full image must share the same aspect ratio. Crop the
  thumbnail with `object-cover`.
</Callout>

## Composition

Use the following composition to build a `Lightbox`

```text
Lightbox
├── LightboxTrigger
└── LightboxContent
    ├── LightboxSlides
    │   └── LightboxSlide
    │       └── LightboxItem
    │           └── LightboxZoom
    │               └── LightboxMedia
    ├── LightboxHeader
    │   ├── LightboxZoomOut
    │   ├── LightboxZoomIn
    │   └── LightboxClose
    ├── LightboxPrevious
    ├── LightboxNext
    └── LightboxFooter
        ├── LightboxCaption
        ├── LightboxCounter
        └── LightboxThumbnailStrip
            └── LightboxThumbnailStripTrack
                └── LightboxThumbnail
```

## API reference

Props pass through to ramka. See the [ramka API reference](https://ramka.dev/docs/lightbox/api).

| Part                                                                                     | Notes                                                                                                 |
| ---------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------- |
| `LightboxContent`                                                                        | Includes the portal and backdrop. Needs `aria-label`.                                                 |
| `LightboxHeader`, `LightboxFooter`                                                       | Hide while pulling to close. The footer also hides while zoomed.                                      |
| `LightboxClose`, `LightboxZoomIn`, `LightboxZoomOut`, `LightboxPrevious`, `LightboxNext` | Render a `Button` with `variant="secondary"` and `size="icon"`, both overridable.                     |
| `createLightboxHandle`                                                                   | Returns a handle with `open(index)`, `close()`, and `goTo(index)`. Pass it to `Lightbox` as `handle`. |

### Spacing

Set on `LightboxContent`, for example `md:[--lb-inset-x:2rem]`.

| Variable            | Default                                            |
| ------------------- | -------------------------------------------------- |
| `--lb-inset-top`    | `4rem`, `4.5rem` from `md`                         |
| `--lb-inset-bottom` | `4rem`, `4.5rem` from `md`, `8rem` with thumbnails |
| `--lb-inset-x`      | `0`, `4.5rem` from `md`                            |

### Data attributes

`LightboxContent` is a `group/lightbox`, so children can use `group-data-zoomed/lightbox:hidden` and the like.

| Attribute                                             | Element                             |
| ----------------------------------------------------- | ----------------------------------- |
| `data-pulling`, `data-pull-dismissing`, `data-zoomed` | `LightboxContent`                   |
| `data-active`                                         | `LightboxItem`, `LightboxThumbnail` |

## Accessibility

- `Escape` closes and returns focus to the trigger.
- Arrow keys move between images, or pan when zoomed. `Home` and `End` jump to the ends.
- `+`, `-`, and `0` zoom in, out, and reset.
- The caption and counter are announced on change.
- Button labels are in English. Pass `children` to translate them.
- With `prefers-reduced-motion`, the morph becomes a fade and the thumbnail strip jumps.
